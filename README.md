# NexRead

NexRead is a backend project developed for the RevoU FSSE assignment. The API is currently in its initial setup phase with NestJS, PostgreSQL, and Prisma ORM.

## Current Progress

- NestJS application scaffold
- TypeScript, ESLint, and Prettier configuration
- PostgreSQL datasource configuration through Prisma
- Initial `User` database model
- Initial migration for the `User` table and unique email index
- Default unit and end-to-end tests from the NestJS scaffold

Authentication and user CRUD endpoints have not been implemented yet.
